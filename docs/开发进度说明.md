## 二、重装系统后只需做 1 件事

### 安装 Node.js 便携版到 E 盘（重装系统不丢）

```powershell
$ProgressPreference='SilentlyContinue'
Invoke-WebRequest -Uri "https://registry.npmmirror.com/-/binary/node/latest-v22.x/node-v22.17.0-win-x64.zip" -OutFile "$env:TEMP\node.zip"
Expand-Archive "$env:TEMP\node.zip" -DestinationPath "E:\软件" -Force
if (Test-Path "E:\软件\nodejs") { Remove-Item "E:\软件\nodejs" -Recurse -Force }
Rename-Item "E:\软件\node-v22.17.0-win-x64" "nodejs"

# 加用户 PATH（仅这行在重装后要做，其他都在 E 盘）
$p = [Environment]::GetEnvironmentVariable('Path','User')
[Environment]::SetEnvironmentVariable('Path', "E:\软件\nodejs;$p", 'User')
```

打开新 PowerShell，`node -v` 应输出 v22.17.0，完成。

**不需要装**：JDK / Android SDK / Xcode —— 双端打包全走 GitHub Actions 云构建。
**不需要装**：Python —— 仅 `server-asr/` 部署到服务器时需要，本机无需。

## 六、首次云构建报错排查清单（按概率排序）

> 所有原生代码未经本地编译验证，首次构建大概率会踩坑。按此顺序排查。

### Android 侧

| 序号 | 可能报错 | 原因 | 修法 |
|---|---|---|---|
| 1 | okio `toByteString` 找不到 | 传递依赖 okio 版本被降到 1.x/2.x | 已在 app/build.gradle 显式写 okhttp 4.12.0，若仍报错加 `implementation("com.squareup.okio:okio-jvm:3.6.0")` |
| 2 | `TYPE_APPLICATION_OVERLAY` 常量找不到 | 编译 SDK < 26 | 工程 variables.gradle compileSdk=35，理论不会；若报改 compileSdk 到 34+ |
| 3 | `handleOnDestroy()` protected 覆写报错 | Capacitor 7 Plugin 类签名变化 | 查 node_modules/@capacitor/android Plugin.java 实际签名，对齐 |
| 4 | `FOREGROUND_SERVICE_MICROPHONE` 权限常量 | 需 API 30+，运行期权限本身不影响编译 | 一般仅 lint 警告，可忽略或提升 targetSdk |

### iOS 侧

| 序号 | 可能报错 | 原因 | 修法 |
|---|---|---|---|
| 1 | pbxproj 工程解析失败 | 手工插入的文件 UUID/引用有格式错 | 用 Xcode 打开让它提示具体行；或重新 `npx cap add ios` 后再手动合并插件代码 |
| 2 | `AVAudioApplication` / `isVideoRotationAngleSupported` 符号找不到 | Xcode < 15（SDK < iOS 17） | workflow 已指定 macos-15 runner；若仍报，改成 `#available` 守卫或回退用 `AVAudioSession` + `videoOrientation` |
| 3 | `CAPPluginReturnPromise` 不可用 | 可能是旧版 Capacitor 宏 | 查 CapacitorCookies.swift 等自带 Swift 文件的用法，对齐写法 |
| 4 | Main.storyboard XML 错误 | `customModule="App"` 与 target PRODUCT_NAME 不匹配 | 确认 target 名是 App；或在 storyboard 里删除 customModule/Provider |

### 通用

| 序号 | 可能报错 | 修法 |
|---|---|---|
| 1 | Gradle 缓存冲突 | `./gradlew clean` 重新构建 |
| 2 | npm ci 锁文件不同步 | 删 package-lock.json 重 `npm install` 再提交 |
| 3 | iOS pod install 卡住/超时 | workflow 里加 `pod install --repo-update` 或跳过 pod 直接 cap sync |

## 八、云端ASR 部署（自有服务器）

```bash
# Linux 服务器
pip install -r server-asr/requirements.txt   # torch CPU 版首次下模型约 1GB
python server-asr/asr_server.py              # 监听 ws://0.0.0.0:8765/ws
```

App 内：设置 → 语音源 → 云端ASR → 填 `ws://服务器IP:8765/ws`。

协议见 `docs/插件接口契约.md` 第四节：客户端先发 config JSON（含 sampleRate=16000），然后发 PCM 二进制帧（16bit/16kHz/单声道），结束发 `{"type":"end"}`；服务端回 partial/final 的累计全文 JSON。
